# 全量格式规范台账

来源：《附件4理工科学位论文格式规范（2026版）.pdf》，17 页。下列页码均为 **PDF 物理页码**，不是样张印出的论文页码。逐页索引及 SHA256 见 [source.md](source.md)。

证据等级只有两种：**明确** = 正文说明或批注直接给出；**样例** = 样张可直接观察到的结构或版式，不自动构成强制要求。一个条目中的多个参数共同描述同一对象。未写出的参数不由相邻条目自动补全。
