# 原文未规定、观察局限与处理方法

以下是来源的边界，不是待用户逐项回答的调查表。能沿用已有文稿时直接沿用；只有影响当前交付且确实需要选择的参数才请用户或学院确认。用户新增要求与学校附件要求分开标记。

| 项目 | 附件证据 | 使用时如何处理 |
| --- | --- | --- |
| 纸张与打印 | PDF 页面尺寸接近 A4；未明示纸张克重、单双面、奇数页起章、封皮材质、装订方式 | 可按 A4 复刻该文件，说明依据是文件尺寸；打印装订要求另核 |
| 页边距与装订线 | 未给出上下左右页边距、装订线、页眉页脚距边界 | 不填入所谓原文规定的 2.5 cm、3 cm 或其他常用值 |
| 封面位置 | 可见居中布局、下划线及校名校徽；没有精确坐标、图片尺寸、区块间距 | 要求像素级或印刷级一致时取得可编辑官方模板；不用截图测量冒充规范 |
| 校名字体及校徽 | 仅有样张素材，未给出可再分发授权 | 使用者提供学校允许使用的原素材；公开仓库不捆绑校徽 |
| 封面题长与日期 | 只有多行题目与年月日示例 | 不臆造题目字数、行数、字距、最低字号或日期来源；所有身份信息以真实资料为准 |
| 专业学位字段 | 专业学位类别写了必填，专业学位领域没有相同必填标识 | 不因领域未标必填便自行删除，也不冒称原文已规定它适用于所有类别 |
| 声明样式继承 | 标题及正文的批注位于独创性声明旁；使用授权声明外观相同但没有重复批注 | 声明页复刻可同样处理，明确授权声明部分的继承是样张观察 |
| 英文摘要 | 没有专门的字体、字号、行距、段间距批注；标题和正文的字形也不相同 | 不直接说原文要求全文 Times New Roman 小四，或把中文标题样式硬套到英文标题 |
| 摘要和关键词篇幅 | 未规定摘要字数、英文词数、关键词数量、词间分隔符强制形式 | 记录样张用逗号；数量与篇幅以学院或用户要求为补充 |
| 目录字体及分页 | 只有样例，目录自身为 1，正文又为 1；目录字号、缩进量及行距未标 | 保留来源事实；采用用户选择的分节策略并注明，不声称目录罗马页码出自此 PDF |
| 页眉横线与页码 | 可见横线和居中页码，但未明示线宽、精确位置及页码字体字号 | 按模板/已有文稿实施；中文摘要页眉的宋体五号是明确要求，其他部分的推广是额外选择 |
| 字体范围 | 正文批注明确中文宋体，参考文献与成果明确英文 Times New Roman | 正文英文、数学字体、英文标题等没有同等明确规定，不扩大 Times New Roman 的明文适用范围 |
| 正文段间距 | 正文批注规定 20 磅和首行 2 汉字，未给段前段后 | 不把摘要或参考文献的零段距自动推广成正文强制要求 |
| 标题粗细与空格 | 章标题明写加粗，二三级标题只写黑体；编号和标题间距未量化 | 黑体与加粗是不同属性；按批注设置，额外加粗或精确空格需标明来自模板/用户 |
| 后置标题 | 附录、参考文献、成果、致谢标题看起来居中加粗，未分别批注具体字号 | 不能一律说原文明确要求它们等同于章标题或摘要标题 |
| 图表细则 | 未规定图片 DPI、宽高、颜色、图中文字大小、图注是否双语、续表、重复表头、线宽 | 不加“必须 300 DPI”“一律英文图注”等外来硬性要求；有额外投稿/学院要求时注明来源 |
| 表格边框 | 正文表是三线表；附录参数表包含竖线 | 根据场景复刻，不能以本文为据禁止所有竖线 |
| 附录编号 | 示例为附录 A、表 A1；没有展示多个附录或附录图号 | 不把 A.1 说成来源编号，也不臆造附录图、公式的规则 |
| 公式、注释及补充列表 | 未给公式对齐、编号、符号表、缩略语表、脚注、算法、代码、图目录或表目录的格式条款 | 按用户/学院补充要求处理；保存可编辑公式，不凭缺少规定删除现有必要材料 |
| 参考文献标准 | 可见顺序数字及期刊例子，未指定 GB/T 7714 版本、DOI、URL、访问日期、作者截断阈值等 | 不宣称某版国家标准已被附件强制采用，不补造缺失文献元数据 |
| 成果条目 | 可见特定作者姓名及刊名加粗、部分 SCI/EI 标记；没有确认加粗姓名对应论文作者本人，也没有说明所有成果必须这样强调或必须收录 | 不编造成果、作者身份或索引收录；示例强调方式与明文字体段落要求分开 |
| 完整章节数量及空白部分 | 样张跳章和省略正文，没有说明所有人必须有附录、成果页或固定六章 | 有相关内容时按样张组织；无内容时根据学院或用户要求决定，不制作虚假条目 |
| 字体视觉复原 | PDF 包含未嵌入字体，部分封面文字在本地显示为方框 | 保留文字层与批注证据；正式提交前在具备相应合法字体的 Word/PDF 环境核查 |
| 版本与权威性 | 附件文件名为 2026 版，未在线核验学校后来是否修订 | 只承诺对这份固定附件的整理；新通知、学院补充与新模板需另行核实 |

对未知参数做出实施选择不等于补充了学校规定。格式报告中分别列出“附件明确”“样张复刻”“用户/学院补充”和“待确认”。
